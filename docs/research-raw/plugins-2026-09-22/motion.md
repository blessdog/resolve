# DaVinci Resolve / Fusion animation, title, transition and motion-graphics packs — research report

Date: 2026-09-22. Machine checked: DaVinci Resolve **Studio 21.1.0** installed at `/Applications/DaVinci Resolve/` (Studio confirmed by `/Library/Application Support/Blackmagic Design/DaVinci Resolve/.license/.davinciresolvestudio_14.0.lic` + RLM dir), macOS (Apple Silicon). Anything marked **UNVERIFIED** was not confirmed against a primary page.

## 0. Ground truth that governs every "scriptable" column

Read from the local install, not from memory — `/Library/Application Support/Blackmagic Design/DaVinci Resolve/Developer/Scripting/DaVinciResolveScript.pyi` (dated 7 Sep 2026) and `CHANGELOG.md` ("21.1 … Added: Transition API - TimelineItem.AddTransition"):

| Format | How the Resolve Python API places it | Verdict |
|---|---|---|
| `.drfx` title / generator / effect (Edit-page Fusion template) | `Timeline.InsertFusionTitleIntoTimeline(titleName)`, `InsertFusionGeneratorIntoTimeline(name)`, `InsertTitleIntoTimeline(name)`, `InsertGeneratorIntoTimeline(name)` — all in the `.pyi` | **SCRIPTABLE by name** once installed in the Effects Library |
| `.drfx` transition | `TimelineItem.AddTransition({type: "<name>", category: "fusion" \| "ofx" \| "simple" \| "audio", position: "start"\|"end", alignment, duration})` — **new in 21.1** | **SCRIPTABLE by name (21.1+)**; on 20.x transitions are GUI-only |
| `.setting` Fusion macro — **the folder decides, not the extension.** (a) Under `Fusion/Templates/Edit/{Titles,Transitions,Effects,Generators}/` it IS an Effects-Library item (a `.drfx` is just a zip of these) → placeable by name with the calls above. (b) Under `Fusion/Macros/` or `Templates/Fusion/*` it is Fusion-page only → `comp.Paste(bmd.readfile(path))` (WSL "Add a Macro via script?" thread; lock the comp first to suppress file dialogs), reaching the comp via `TimelineItem.AddFusionComp()` / `GetFusionCompByName()` | **SCRIPTABLE either way**; (a) by name from Resolve, (b) two-step Resolve API → Fusion comp → Paste. The 14 project titles on this machine are case (a) |
| `.comp` Fusion composition | `TimelineItem.ImportFusionComp(path)` | **SCRIPTABLE** |
| OFX plugin | `Timeline.InsertOFXGeneratorIntoTimeline(name)` for generators; `AddTransition(category="ofx")` for transitions; OFX filters are applied via Fusion comp or the Color page (no direct "AddOFXEffectToClip" in the `.pyi`) | **PARTLY scriptable** |
| `.drp` project / timeline template ("template project") | `ProjectManager.ImportProject()` / `Timeline.ImportIntoTimeline` only bring the whole thing in; placeholder swapping is GUI | **GUI-only in practice** |
| Fuse (`.fuse`) / compiled plugin (`.plugin`) | Appears as a Fusion tool: `comp.AddTool("ToolID")` | **SCRIPTABLE in Fusion** |
| Lottie `.lottie` / OGraf `.json` (new in 21) | The guide says drag-and-drop into Media Pool/timeline "like any other media"; `MediaPool.ImportMedia([path])` → `AppendToTimeline` accepting these extensions is **inferred, not tested**; `OGrafLoader` node in Fusion is `comp.AddTool` | **SCRIPTABLE (inferred)** |

Apple Silicon rule: `.drfx`, `.setting`, `.comp`, `.fuse`, Lua scripts are architecture-agnostic text/zip — they run wherever Resolve runs. Only compiled OFX/`.plugin` binaries have a real Apple Silicon question; those rows say what the vendor states.

Also verified locally (unzipped `Resolve.app/Contents/Resources/Fusion/Templates/Templates.drfx`, 29.6 MB): Resolve 21.1 ships **134 Fusion titles, 67 Fusion transitions, 29 effects, 44 generators (21 of them "Stinger Transitions")** on the Edit page, plus Fusion-page bins (Styled Text 16 macros incl. `3D Follower`, `Scramble Modifier`, `Odometer`, `Flip Follower`; Motion Graphics 5; Tools 3 incl. `Advanced Camera Shake`; 523 lens-flare files; 289 particle files; 354 shader files). Built-in transitions already include `Camera Shake`, `Crash Zoom`, `Zoom In`, `Glitch`, `Block Glitch`, `RGB Splitter`, `Stretch Blur`, `Film Strip`, `Page Curl`. And `krokodove.plugin` + `ograf.plugin` sit in `Resolve.app/Contents/Libraries/Fusion/Plugins/` — Krokodove is now built in.

The user Titles folder on this machine already holds 14 project-authored `.setting` titles (`MS BR *`, `MS DOC *`, `MS ND *`, `MS PC *`, `Media Studio Smoke`) and an `OGraf/` folder.

## Top picks for a solo creator (Resolve 21.1 Studio, Apple Silicon, scripted pipeline)

Start from what is already installed: the 134/67/29/44 Edit-page templates in `Templates.drfx` are the only pack whose names the scripting API is guaranteed to accept today (`InsertFusionTitleIntoTimeline`, `AddTransition(category:"fusion")` on 21.1), and 21 folded Krokodove, Lottie/OGraf import, the Fairlight Animator and the Juggle/Write text modifiers into the free base — most "glitch/shake/typewriter" packs are now redundant. Install **Reactor Standalone** once and pull **Vonk Ultra + FusionMograph, MT_GlitchTools, Suck Less Write On, Follower In Time, Anim Utility, Flux Super Transform, Echo, ExponentialGlow/Flare Tools, FUI Designer, FrameTools CapCut Captions** — all free, all `.fuse`/`.setting` (architecture-agnostic), all reachable by `comp.Paste`/`comp.AddTool`. For a paid design lift, the honest choices are **Envato Elements Core ($16.50/mo)** filtered to `.drfx`/`.setting`, or **Motion Array ($29.99/mo)** for the deepest macro catalogue; buy **MotionVFX DVR packs** only with eyes open — Apple bought the company on 2026-03-16 and the Resolve line's future is unstated. For kinetic type beyond Follower, **sh4rk 3D Text Animator Pro ($18.90)** and **Allavio Text Animator ($14.99)** are the cheap, Resolve-21-compatible options; FxFactory Motype 2 is the premium Mac-only one. Skip Mixkit (R16-era `.comp`), RocketStock (now Shutterstock, no Resolve items), Lenofx (FCP-only as far as anything shows) and any "Ground Control preset pack" (it's a course site).
